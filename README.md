### About Me

Firmware and embedded systems engineer focused on microcontroller-based system design, register-level hardware interfacing, and real-time deterministic software. Experienced in designing inter-MCU communication pipelines, custom peripheral drivers, and low-latency control logic across ARM Cortex-M (STM32) and Espressif (ESP32) architectures.
